# SOFT410-TeamC-ECommerce — E-Commerce3

Gradle build of the given E-Commerce3 source code.

## Build & run
```bash
./gradlew clean build     # compile + run tests      (Windows: gradlew.bat clean build)
./gradlew test            # run JUnit 5 tests (+ JaCoCo coverage report)
./gradlew run             # run Main
```
Reports: `build/reports/tests/test/index.html`, `build/reports/jacoco/test/html/index.html`

Requires JDK 17+.
